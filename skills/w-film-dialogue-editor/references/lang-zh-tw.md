# 台灣國語對白指南

## 一、核心立場

台灣國語的語氣比大陸普通話更軟、更綿。常見語氣詞為「啊、欸、耶、啦、嘛、嘞、喔、囉、哦、吼、餒」，句尾常帶「的啦／好不好／是不是／對不對」。語助詞「就、然後、其實、真的、有點」使用頻率高，寫成對白時要克制，避免變成口頭禪式贅詞。

可夾英語單字（OK、no、yeah、sorry、bye、case），密度低於港式中英夾雜。閩南語、客語零星滲入是身份標記（「歹勢、阿娘喂、靠北、衝啥小、啥米代誌、夭壽喔」），按角色背景使用。粗口（「靠、幹、操你媽、王八蛋、靠北、機掰、智障」）尺度與大陸略異，按平台與類型調整。避免把台灣國語寫成書面普通話加幾個「啦」就交差。

## 二、元素規則

台灣國語比大陸普通話更綿、更軟，語助詞密度高。寫作時要按角色克制贅詞，不要把「就、然後、其實、真的」當填充物。

| 元素 | 用法 | 風險 |
|---|---|---|
| 語氣詞 | 「啊、欸、耶、啦、嘛、嘞、喔、囉、哦、吼、餒」標態度。 | 過多會像綜藝口白。 |
| 句尾結構 | 「的啦／好不好／是不是／對不對／齁」推出問句或反問。 | 機械重複會無情緒。 |
| 語助詞 | 「就、然後、其實、真的、有點、稍微」做口語節奏。 | 變口頭禪會稀釋戲劇張力。 |
| 英語夾雜 | 「OK、no、yeah、sorry、bye、case」適度使用。 | 密度過高會像港式 ABC。 |
| 閩南／客語滲入 | 「歹勢、阿娘喂、靠北、衝啥小、夭壽喔、啥米代誌」做身份標記。 | 不符背景會跳。 |
| 粗口 | 「靠、幹、操你媽、王八蛋、靠北、機掰、智障」按平台與尺度。 | 跨地域使用要核對是否串味。 |

## 三、快速自檢

- 語助詞「就、然後、其實、真的、有點」係節奏，唔係填充物；一句最多一個。
- 「的啦／好不好／是不是」係句尾結構，唔好每句都加。
- 閩南語、客語滲入係身份標記，要符合角色背景。
- 唔好把台灣國語寫成「書面普通話 ＋ 幾個啦」。
