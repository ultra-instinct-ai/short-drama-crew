# 日文對白指南（東京標準語為主／関西弁為輔）
本文件供日文對白任務使用：原創日文劇本、把中文劇本轉成日文版、校對字幕與配音稿、為日本市場的短劇做在地化。核心立場同其他語言一致——對白係人物在壓力下的行動，唔係資訊傳輸；但日文的敬語系統、主語省略、終助詞與ウチ／ソト意識，令逐字翻譯幾乎一定出戲。以**東京標準語（共通語）**為主軸、**関西弁**作對照，敬語以**現代商務日語**為準，唔寫昭和式過度敬語。

## 一、先定三件事

寫日文對白之前先答三條問題；答錯任何一條，之後幾多修辭都救唔返。

### 1.1 地區：東京標準語 vs 関西弁

| 項目 | 東京標準語 | 関西弁（大阪） | 使用判斷 |
|---|---|---|---|
| 否定 | 行かない | 行かへん | 関西背景角色用；半混最難聽 |
| 斷定 | そうだよ | せやで | 一句東京一句大阪＝即刻出戲 |
| 不行／拒絕 | だめ／無理 | あかん | 「あかん」帶人情味，勸阻、講價常用 |
| 感謝／道歉 | ありがとう／ごめん | おおきに／すんません | 老舖、年長者、關西商業場景高頻 |
| 吐槽 | 何言ってるの | なんでやねん | 喜劇節奏嘅核心拍子 |

関西弁係一套完整語法，唔係「標準語講歪」。最難聽嘅做法係東京角色偶爾加一句「せやな」扮親切——觀眾一聽就知編劇唔識。関西仲有敬語形「〜はる」（見下表），係對長輩、客人用嘅正式講法。

| 標準語（尊敬語） | 関西弁（〜はる） | 備註 |
|---|---|---|
| 行かれる／いらっしゃる | 行かはる | 對長輩、客人都用；東京人聽落覺得親切 |
| 食べられる／召し上がる | 食べはる | 年輕角色互相用會過敬，同輩之間用返タメ口 |
| される／なさる／言われる | しはる／言わはる | 唔可以同標準語尊敬語混：冇「いらっしゃはる」 |

### 1.2 ウチ／ソト（內外關係）

| 場面 | ウチ（內） | ソト（外） | 語言後果 |
|---|---|---|---|
| 公司內部 | 同僚、部下 | — | タメ口可，但對上司仍要丁寧 |
| 面對客戶 | — | 客戶、供應商 | 丁寧語＋謙譲語；自己公司的人一律降格 |
| 家庭 | 家人 | 訪客、鄰居 | 對家人タメ口，訪客一到即刻切り替え |
| 朋友聚會 | 熟人 | 初次見面 | 全場只有一個人講敬語＝關係信號 |

先問「呢場戲嘅ウチ係邊個」：同一個課長，社內叫「田中さん」，對客就係「田中が申しておりました」。

### 1.3 語域三檔

| 語域 | 形式 | 對象 | 例 |
|---|---|---|---|
| 丁寧語（ですます） | 〜です／〜ます | 初對面、客、目上 | 少々お待ちください |
| タメ口（常體） | 〜だ／〜る | 同輩、朋友、家人、目下 | ちょっと待って |
| 尊敬語・謙譲語 | 動作の向き | 客・目上／自己的動作 | ご覧になりますか／拝見しました |

固定 register 靠三點：**一人稱**（俺／僕／私／あたし／わし）＋**文末**（だ／です／っす）＋**呼稱**（さん／くん／呼び捨て）。三點一致；故意唔一致就係戲——電話用敬語，一收線即刻轉タメ口。

## 二、敬語三層

敬語唔係越高越好。日劇真正嘅高手係丁寧語打底，關鍵位落一發尊敬語，令對方即刻坐直；成套尊敬語反而似電話錄音。

| 動詞 | 尊敬語（對方動作） | 謙譲語（自己動作） | 丁寧語 | 螢幕場景 |
|---|---|---|---|---|
| 言う | おっしゃる | 申す／申し上げる | 言います | 轉述上司指示 |
| 行く | いらっしゃる／おいでになる | 伺う／参る | 行きます | 去客先 |
| 来る | いらっしゃる／おいでになる／見える | 参る | 来ます | 迎接客戶 |
| いる | いらっしゃる | おる | います | 確認在席 |
| 食べる | 召し上がる | いただく | 食べます | 接待、請客 |
| 見る | ご覧になる | 拝見する | 見ます | 遞資料 |
| する | なさる | いたす | します | 請託 |
| もらう | お受け取りになる | いただく | もらいます | 收件、收禮 |
| あげる | お与えになる（偏書面） | 差し上げる | あげます | 送手信 |

- **尊敬語同謙譲語係方向**：尊敬語只講對方動作（「私がいらっしゃいます」係最典型嘅錯）；謙譲語壓低自己，對社外唔可以抬自己公司嘅人。
- **丁寧語係底**：八成場面丁寧語已經夠；唔肯定就用丁寧語——二重敬語比唔用敬語更失禮。

**二重敬語同バイト敬語（常見錯）**

| NG | 問題 | 改 |
|---|---|---|
| おっしゃられる／ご覧になられる | 敬語形＋られる | おっしゃる／ご覧になる |
| お伺いさせていただきます | 伺う＋させていただく | 伺います |
| お召し上がりになられる | 三重敬語 | 召し上がります |
| させていただきます（濫用） | 許可の意味が消える | します |
| よろしかったでしょうか | 過去形が不自然 | よろしいですか |
| 千円からお預かりします | 「から」不要 | 千円お預かりします |
| こちらコーヒーになります | 「になる」係變化 | コーヒーです |
| お水のほうお持ちしました | 「のほう」無意義 | お水お持ちしました |

## 三、終助詞與語氣

日文角色嘅態度，七成落喺句尾一粒字。**一句最多一個終助詞**，兩個已經係強烈情緒，三個就係綜藝口白。

| 終助詞 | 態度 | 例 | 用錯後果 |
|---|---|---|---|
| よ | 告知、帶上目線 | 明日、休みだよ | 對客用「よ」＝教訓人 |
| ね | 同意要求、拉近 | いい天気ですね | 連續「ね」＝逼人附和 |
| よね | 確認＋施壓 | 明日、来るよね？ | 溫柔問句變質問責 |
| さ | 輕鬆、投げやり | まあ、そういうこともあるさ | 上目線，女性少用 |
| な | 感嘆／禁止 | 危ないな／行くな | 語調一錯就變命令 |
| なあ | 感慨、独り言 | いいなあ | 對人講＝唔理人 |
| かよ | 反語、不信 | なんだよ、それかよ | 直接挑釁，客前 NG |
| じゃん | 開き直り | 前も言ったじゃん | 關東若者；對上司＝不遜 |
| っす | 輕敬語、体育会系 | 了解っす／マジっすか | 半端敬語，接客 NG |
| ぞ | 男性、威壓／独り言 | 行くぞ | 對客＝威脅 |
| ぜ | 男性、邀約 | 行こうぜ | 女性角色用＝演出痕跡重 |
| わ | 柔軟斷定 | もう帰るわ | 關西用法更強、帶怒 |
| もの（もん） | 辯解、撒嬌 | だって仕方ないもん | 成年男性用＝幼稚 |
| かな | 婉曲、迷い | そろそろ行こうかな | 該決定時用＝優柔不断 |
| でしょ | 確認、押付 | だから言ったでしょ | 對客＝責備 |
| だろ | 男性、詰め | だから言っただろ | 一講就變吵架 |
| のに | 不滿、可惜 | 言ったのに | 對客＝埋怨 |
| けど | 前置き、婉拒 | 悪いけど、今日は無理 | 句尾「けど」＝話未講完，空氣中斷 |
| かしら | 女性、上品（偏舊） | これ、合うかしら | 年輕角色用＝動畫腔 |

堆砌係最常見嘅病：「そうだよねー、わかるよー、でもさー」——呢句係綜藝主持，唔係人講嘢。

## 四、稱謂與呼び方

| 稱謂 | 對邊個 | 例 | 禁區 |
|---|---|---|---|
| さん | 預設，保持恰當距離 | 田中さん、いいですか | 對自己公司的人講「さん」俾客聽＝NG |
| くん | 男性同輩／目下 | 佐藤くん、これ頼む | 對女性部下用＝軍隊感 |
| ちゃん | 親密、可愛 | みきちゃん、おいで | 對客、對上司＝失禮 |
| 様 | 客、通知、書面 | お客様、お呼び出しです | 日常對話用＝機械感 |
| 先生 | 教師、醫、議員、律師 | 先生、質問いいですか | 對普通同事用＝叫錯人 |
| 先輩 | 同組織內年長 | 先輩、これどうすれば | 對客唔用 |
| 課長／部長／社長 | 役職呼び | 課長、お時間よろしいですか | 對社外用＝NG |
| 呼び捨て | 親密／目上から目下 | 田中、来い | 對客、對上司＝宣戰 |

由姓轉名係日本戲最重要嘅關係刻度，正常由**對方**開口「下の名前で呼んでいいよ」；主角搶先叫名＝越界。呼び捨て係另一個刻度，用錯等於侮辱，用得準等於親密。對社外要**降格**：「田中は席を外しております」，唔可以講「田中課長はいらっしゃいません」。

## 五、句法特徵

- **SOV＋省略＋一人稱**：動詞放最後、修飾語在前，倒裝係張力工具（「行ったよ、昨日、一人で」）；主語預設省略，寫出來就係強調或發難（「私がやった」）；俺／僕／私 一場戲內漂移就係編劇痕迹。
- **だ・である vs 會話**：である 係旁白、論文、演說；會話常體係「だ＋終助詞」；ですます 係距離；體言止め（「以上。」「理由は一つ。」）適合反派。
- **相槌要寫**：「うん」「へえ」「そうなんだ」係日文對話嘅呼吸；一句都冇，會覺得兩個人在讀稿。

## 六、年齡層速查

- **kid（6–12）**：「ねえねえ、これ見て！」「ずるい！」「もう一回！」「ママー、トイレー」——語尾上揚、撒嬌、句子短。
- **teen（13–19）**：「まじで？」「うざっ」「きもい」「てか、だるくない？」——「っ」切句、若者語，對長輩轉敬語仲未上手。
- **young（20–29）**：「めっちゃいいじゃん」「やばい、間に合わない」「とりま行こ」「りょ」——氣氛優先，敬語係「っす」混住。
- **mid（30–44）**：「さすがにそれはないでしょ」「ちょっと確認します」「助かります」——場面切換純熟，推責任嘅講法多。
- **senior（45–59）**：「そうですねえ」「まあ、いいんじゃない」「最近の若い人はねえ」——句尾拉長、帶評價、斷定。
- **elder（60+）**：「ありがとうねえ」「えらいねえ」「わしが若い頃はな」「おおきに」——方言與老派詞、慢、常帶人生教訓。

## 八、粗口／髒話分級

| 級 | 詞 | 語感 | 平台 |
|---|---|---|---|
| p1 | バカ、アホ、うるさい、ムカつく、うざい、最低 | 日常鬧人，唔破壞關係 | 全部可 |
| p2 | クソ、バカ野郎、てめえ、ふざけんな、消えろ | 明確敵意，吵架入口 | 地上波限深夜；配信可 |
| p3 | 死ね、殺すぞ、カス、ゴミ、手前 | 放送禁止級、威脅 | 地上波 NG；TikTok 有刪片風險 |

| 平台 | 尺度 | 處理 |
|---|---|---|
| 地上波 | 最嚴（BPO 放送コード） | 「死ね」NG、差別語 NG，p1 止 |
| Netflix／Prime | 寬 | p3 可，但差別語、侮辱實存人物照樣出事 |
| YouTube | 廣告收益與年齡限制風險 | p2 止；開頭 3 秒要乾淨 |
| TikTok／Shorts／縱向短劇 | 自動偵測＋平台審查，日本市場接近地上波 | p1 為主，p2 靠 bleep 或切斷 |

地域差要留神：關西で「アホ」係親密、「バカ」係侮辱；東京大致相反，但「アホか」兩地都係挑釁。粗口係**角色刻度**，唔係強度旋鈕。

## 十、中→日 transcreation 陷阱

| 中文／漢字面 | 以為係 | 實際處理 |
|---|---|---|
| 大丈夫です | 沒問題 | 亦係婉拒：店員問「袋いりますか」→「大丈夫です」＝不用 |
| 検討します | 會考慮 | 商務上多數＝拒絕；「前向きに検討します」更似拒絕 |
| 麻煩你了 | 一個講法 | お手数をおかけします（求人）／よろしくお願いします（收線）／悪いね（朋友） |
| 知道了 | 一個講法 | 了解しました（同事）／承知しました（客、書面）／かしこまりました（接客）／わかった（同輩） |
| 加油 | 頑張って | 只可上對下或同輩；對上司用「応援しています」「ご健闘をお祈りします」 |
| 沒關係 | 大丈夫 | 對客用「とんでもないです」更得體 |
| 隨便 | なんでもいい | 易失禮；改「おまかせします」「何でも大丈夫です」 |
| 你辛苦了 | お疲れさま | お疲れさまです（同事）／ご苦労さま（只可上對下，反用＝侮辱） |
| 好的 | はい | 對客只可 はい／かしこまりました；「了解です」對客偏輕 |
| 我再想想 | 考えさせて | ちょっと考えさせてください（真考慮）／検討します（婉拒） |
| 我請客 | おごる | おごります（朋友）／ごちそうします（約會、正式，較 soft） |
| 稱謂 | さん 萬用 | 「王さん」可；「小王」NG；「先生」係老師／醫生，唔係 Mr. |

## 十一、字幕／配音腔（翻訳調）常見病

| 病 | 例 | 改法 |
|---|---|---|
| 主語過多 | 私はあなたのことが好きです | 好きだよ |
| 代名詞連發／直譯「あなた」 | あなたはどう思いますか／彼は、彼女は | どう思う？；改名字或省略（あなた 只剩妻子叫丈夫、或吵架） |
| 過度敬語 | 友達に「お元気でいらっしゃいますか」 | 元気？ |
| 句尾一律です／文語混入 | 全部「〜です」；会話に「〜である」「〜なのだ」 | 會話混 だ／よ／ね／じゃん；〜だよ／〜んだよ |
| 書面接続詞 | しかし／なぜなら／したがって | でも／だって／だから |
| 感嘆詞直譯 | 「ああ」「おお」 | え／うわ／まじで |
| 語順照搬 | あなたは私にそれを教えた | それ、教えてくれたよね |
| 敬語與タメ口混線／冇附和 | 同場兩種 register；兩人輪流講完整句 | 固定 register；加 うん／へえ／そうなんだ |

## 十二、自檢清單

- [ ] 三點 register 定咗而且一致：一人稱、文末、呼稱。
- [ ] ウチ／ソト 切換位（尤其對客場面）正確。
- [ ] 敬語層數對（冇二重敬語、冇バイト敬語），對社外有降格（「田中は席を外しております」）。
- [ ] 每個角色 1–2 個 signature 終助詞，冇堆砌。
- [ ] 敬語／タメ口 切換有戲劇理由，唔係隨機。
- [ ] 主語省略自然；冇一句一個「私は」。
- [ ] 冇直譯「あなた」「彼／彼女」。
- [ ] 関西弁冇半混：一係成套，一係唔用。
- [ ] 婉拒用法冇譯錯（大丈夫です／検討します／ちょっと…）；年齡層詞彙對（teen 唔講長輩語）。
- [ ] 粗口級別符合平台，開頭 3 秒乾淨。
- [ ] 相槌、間（ま）有寫，唔係兩人輪流讀稿。
- [ ] 商談／接待場面：敬語係角色武器，唔係背景音；用得愈準，翻臉時愈痛。
- [ ] 遮住角色名讀一次，仍然分得出邊個講。
