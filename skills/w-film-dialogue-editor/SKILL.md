# Film Dialogue Editor

## 使用時機

當用戶要求校對、修改、潤飾、重寫、粵語化、港式化、普通話化、國語化、英文化、自然化、加強潛台詞、檢查角色口吻、改善節奏、修改劇本對白或提供導演／演員講戲提示時，使用此技能。亦適用於原創英文對白、把中文劇本轉成英文版、校對非母語者寫的英文對白，以及歐美短劇在地化。適用文本包括電影劇本、短劇單集、劇集分場、分場大綱中的對話、角色訪談式獨白，以及需要改成可拍攝對白的散文式內容。

接到任務時先確認本劇預設語體：粵語／港式、大陸普通話、台灣國語、港式普通話、古裝／年代戲普通話、或英文（美式為主）、韓文（首爾標準語／사투리）、日文（標準語／関西弁）。若用戶未說明，依劇本既有用詞推斷並向用戶確認；不要默認改成書面中文。

若任務是「中文稿轉英文版」，先確認這是 **transcreation（再創作）而非 translation（翻譯）**：保住場面目標、人物策略與轉折，重寫語言表層。同時確認目標地區（美式為主／英式為主／混合）、角色世代、投放平台尺度，再開始逐句處理。

## 核心原則

把對白視為**人物在場面壓力中的行動**。不要只把句子改得順口；要判斷角色此刻想得到甚麼、對方如何阻擋、角色為何不直接說真話，以及這句話說完後局面是否改變。

優先保持用戶原本的故事意圖、角色設定、類型語氣與語言地域。若資料不足，不要擅自重設人物背景；先明確標示假設，必要時詢問用戶補充前後情節、角色關係、地域語言、尺度要求和修改幅度。

## 工作流程

| 步驟 | 行動 | 目的 |
|---|---|---|
| 1 | 讀取用戶文本，辨認場面、角色、關係、衝突、類型與語言要求。 | 避免只做表面潤色。 |
| 2 | 判斷修改幅度：輕修、中修或重修。 | 控制改稿力度，避免過度重寫。 |
| 3 | 先做整體診斷，再做逐句校對。 | 先解決戲劇問題，再處理字句。 |
| 4 | 修改對白的功能、潛台詞、角色聲音、資訊處理與節奏。 | 令對白更有電影性和可演性。 |
| 5 | 提供整場修改版，必要時提供導演／演員提示。 | 讓用戶可直接採用或拍攝。 |

## 修改幅度

| 幅度 | 適用情況 | 操作方式 |
|---|---|---|
| 輕修 | 用戶文本基本成立，只需更自然、更口語、更準確。 | 保留原句結構，修語氣、節奏、錯字、贅詞與少量口吻。 |
| 中修 | 對白略直白、資訊太多、角色聲音不夠分明。 | 重組句子、刪減說明、加強攻防、調整潛台詞。 |
| 重修 | 場面缺乏衝突、人物目的不清、對白不可演。 | 重新設計場面節拍、人物策略和整段對話，但保留故事意圖。 |

## 診斷標準

檢查每句對白是否有戲劇功能。若一句話不推動劇情、不揭露角色、不改變關係、不製造衝突、不承載主題，也不建立節奏，通常應刪除或改寫。檢查角色聲音是否獨特；若遮住角色名後無法分辨誰在說話，應按年齡、階層、職業、教育、地域、親密距離與防衛機制重寫。

檢查潛台詞是否存在。若角色把感受、目的、背景和主題全部直接講出，應改成試探、否認、迂迴、玩笑、攻擊、照顧動作或沉默。檢查 exposition 是否太方便；熟人不應互相解釋雙方早已知道的事，應把資料藏入控訴、責任、交易、威脅、笑話或選擇。

如需診斷維度、修改優先級同輸出格式，讀取 `references/dialogue_revision_framework.md`。**若任務涉及韓文或日文對白（韓劇／日劇改編、字幕、配音、中文稿轉韓／日版），必須先讀 `references/lang-ko.md`／`references/lang-ja.md`，唔可以靠英文或中文規則套落去。**

**若任務涉及英文對白、中文轉英文版或歐美市場在地化，必須讀取 `references/lang-en.md`**，該文件涵蓋中→英 transcreation 陷阱、美式階層／地域／族裔分層、英式英語、世代語言、年代對照、社媒與時尚圈行話及平台尺度。如需標準報告格式，可使用 `templates/dialogue_revision_report.md`。

4. 逐句改；最後用該 guide 嘅自檢清單收貨。



## 輸出方式

除非用戶只要求簡短潤色，否則使用以下結構輸出。先用一段完整文字說明整體診斷，再用表格做逐句修改，最後提供整場修改版。表格欄位建議為「原句」、「問題」、「修改句」、「修改理由」、「導演／演員提示」。

| 輸出部分 | 要求 |
|---|---|
| 整體診斷 | 說明場面主要問題、人物攻防、潛台詞和修改策略。 |
| 逐句校對表 | 每句給出問題、修改句和修改理由。 |
| 整場修改版 | 保持劇本格式，提供可直接貼回稿件的版本。 |
| 導演提示 | 用可執行動詞描述表演行動，例如逼、哄、避、刺、求、試探。 |
| 後續問題 | 只在必要時詢問缺失資料，不要用過多問題阻塞工作。 |

## 導演／演員提示規則

不要只寫「自然一點」、「傷心一點」、「激動一點」。改用可演行動，例如「你不是解釋，你是在逼對方認錯」、「你講笑不是為了好笑，而是為了不讓對方看見你怕」、「這句停半拍，因為角色在決定是否把真正的話吞回去」。

## 保護原作規則

保留用戶指定不可改的金句、角色名、設定、劇情資訊和語言風格。若必須大幅改寫，先在輸出中註明「以下為重修示範」。若用戶提供的是完整劇本，只修改與對白相關的內容，不主動改變主線、人物命運或場景結構，除非用戶明確要求。

## 品質檢查

交付前檢查新版對白是否更短、更有目的、更貼近角色、更有潛台詞、更容易表演，並且沒有把所有角色改成同一種口吻。若是粵語版本，朗讀時應自然，不應像書面中文硬轉廣東話。若是普通話版本，按既定語體（大陸／台灣國語／港式普通話／古裝年代）檢查語氣詞、用詞時代、地域口音與英語夾雜的密度；避免大陸、台灣、港式三種口吻互相串味，避免現代詞滑入古裝戲，亦避免把粵語語氣詞「啦／喇／啫」直接搬入普通話。若劇本含多語體角色，檢查每個角色的語體標記是否一致。

若是英文版本，逐項核對：contraction 是否已縮寫、不縮寫者是否都有戲劇理由；一場戲直呼對方名字是否超過兩次；是否有超過 20 字而無理由的長句；是否殘留 "I hate you" 式情緒宣言；遮住角色名朗讀是否像字幕（成語直譯、敬語殘留、主語缺失）；美式角色是否誤用英式詞（flat／trainers／mobile）或反之，是否有角色同時帶兩地標記；slang 是否符合角色出生年、是否堆砌過密；AAVE 或其他社群語言是否從角色出發而非刻板印象、是否被用來標記反派或笑點；時尚／KOL 行話是否服務角色的專業自信與權力關係而非炫技；粗口密度是否符合投放平台、開場 3 秒是否乾淨。完整清單見 `references/lang-en.md` 第八節。

若是韓文或日文版本，按 `references/lang-ko.md`／`references/lang-ja.md` 嘅自檢清單核對：同一對關係內嘅敬語階層（합쇼체／해요체／반말；ですます／尊敬語・謙譲語／タメ口）有冇前後不一、終助詞／語尾有冇堆砌、稱謂同內外關係（우리／うち）是否正確、有冇字幕腔直譯（예：主語過多、直譯「あなた」）。

若同時交付中文版與英文版，兩版必須場面目標、人物策略與轉折一致，但**不要求句句對應**——英文版可合併、拆分或改變攻防順序，只要戲劇功能相同。
