# Continuity & Blocking Pull-Fit (Producer gate)

Permanent gate. Runs on **every** episode script **before greening**, **in parallel with** `producer-dialogue-performance-qa.md` (Dialogue performance pull-fit). Applies to **all future episodes / projects**, not only E02.

**P0 FAIL** → blocks script green **and** burning (paid video).  
**P1** → may green only with explicit note; **must fix before burning**.  
**P2** → minor; fix when convenient.

## Checklist

| # | Verify | P0 | P1 | P2 |
| --- | --- | --- | --- | --- |
| 1 | **Position bridges** — every 坐↔站↔跪↔趴／拖起／扳轉／轉身 is an explicit connecting `△` move; **no silent jumps** (e.g. 坐→跪, 站→跪, 拖起) | Silent pose/place jump | Soft side L/R only | Timestamp nits |
| 2 | **Relative seating / standing** — at each scene beat it is clear where every on-screen character sits/stands relative to others (sofa / 双膝前 / 侧站 / 扶手后…) | Two characters occupy impossible same spot or lost relative place | Vague “旁边” without furniture anchor | Redundant repeat |
| 3 | **Action chains** — every physical action has a **connecting movement** into the next; no action-to-action jumps | Next beat impossible from prior body state | Soft timing | — |
| 4 | **Prop tracking** — every prop’s on-screen location tracked from **first appearance → final use**; anything used mid/late must be **pre-placed** in an early beat with a **visible** stage direction | Prop appears from nowhere at use | Prop exit unclear but unused later | Cosmetic prop |
| 5 | **Presence** — no character vanishes from frame without **stated exit / hide / off-side / re-entry**; friends/crowd from brief stay tracked | Named on-screen character disappears | Soft crowd attention only | — |

## How to run

1. Walk all `△` beats in order; keep a mental (or note) board of positions + props.
2. List findings as P0 / P1 / P2 with quoted beat + one-line fix.
3. Any P0 → bounce Screenwriter; do not green. Clear P0 → green only if Dialogue performance pull-fit also PASS.
