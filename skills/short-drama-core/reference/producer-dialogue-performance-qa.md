# Producer dialogue performance QA — pull-fit gate

Recurring **pull-fit** checklist before an episode script is **green** and before any later script re-lock / Proofreader pass that touches dialogue. Applies to **every project going forward**, not a single episode.

Run on the episode script (`E0N-SCRIPT.md` / `episodes/E0N.json` spoken lines). Any FAIL blocks script green and paid gen until revised.

## Pull-fit — every dialogue line

For **each** spoken line (character dialogue and on-screen VO that carries story emotion):

| # | Check (粵) | Check (EN) | PASS | FAIL |
| --- | --- | --- | --- | --- |
| 1 | **對白有冇交代清楚** | Is the emotional state / emotional context at the moment the line is spoken clearly established in stage directions (`△`), delivery parentheticals, VO setup, or surrounding beats? | Reader can name what the speaker feels/wants *as they speak* without inventing | Line floats; emotion only implied; bare「生气」with no setup |
| 2 | **點樣演繹** | Is how the actor should perform/deliver that line specified (tone, physical state, intention)? | Concrete delivery: e.g. 怜香惜玉、半闭眼享受、声软宠、破音尖叫、牙关紧 | Missing delivery; emotion-only tag; Director would have to invent performance |

Examples of good delivery (action + state, not bare emotion): `（怜香惜玉，半闭眼享受，声软宠）` · `（破音尖叫，脸歪）` · `（明知故问，带着笑）`.

## How to sign

1. Walk every line in order. Mark PASS / FAIL per line (or batch FAIL with line quotes).
2. FAIL → bounce Screenwriter with exact lines + which check failed. Do not green.
3. PASS all lines → script may go green (language Proofreader still applies where relevant).

Footer template:

```
Dialogue performance pull-fit — E0N
Lines checked: N
Check 1 對白有冇交代清楚: PASS / FAIL
Check 2 點樣演繹: PASS / FAIL
Failed lines: (none | quote…)
Signed: Producer · date
```

## Where it sits in the pipeline

- **Before** Stage 4 script green (every episode, every rewrite lock).
- **Again** on any material dialogue rewrite before storyboard / paid video.
- Proofreader may re-run the same two checks when auditing script/@audio; FAIL still blocks paid gen.
